# EV Battery Health Prediction Using Deep Learning

## 1. Project Overview

This project develops an Artificial Neural Network
(ANN) based classification model to predict EV
battery conditions using battery-related parameters.

## 2. Objective

The objective is to explore how deep learning
can be used to classify battery conditions and
support intelligent battery monitoring.
